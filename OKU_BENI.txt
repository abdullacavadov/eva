E.V.A Windows mühitində işləyən, Gemini Live API əsaslı səsli AI köməkçisidir.


─────────────────────────  QURAŞDIRMA  ─────────────────────

1) Python 3.10+ quraşdır.
   Quraşdırma zamanı "Add Python to PATH" seçimini aktiv et.

2) Repository-ni lokal kompüterə köçür.

3) Virtual mühit yarat və aktivləşdir:

   python -m venv venv
   venv\Scripts\activate

4) Paketləri quraşdır:

   pip install -r requirements.txt
   pip install -r requirements-dev.txt


─────────────────────────  BAŞLATMA  ───────────────────────

   Əsas variant:

   python main.py

   Windows üçün BASLAT.bat faylından da istifadə edə bilərsən.


─────────────────────────  API AÇARI  ──────────────────────

E.V.A Gemini API açarından istifadə edir.

API açarını tətbiqin konfiqurasiya mexanizmi vasitəsilə əlavə et.

Google Calendar üçün ayrıca Google OAuth prosesi tələb olunur.
İlk qoşulmadan sonra real Google Calendar tokeni config qovluğunda saxlanılır.
Token faylını Git repository-yə əlavə etmə.


─────────────────────────  XÜSUSİYYƏTLƏR  ──────────────────

   • Real vaxtlı səsli söhbət
   • Yazılı komanda daxil etmə
   • Tətbiq açma
   • Sistem məlumatlarını alma
   • Təhlükəsiz shell əmrlərinin icrası

   • Xatırladıcılarla işləmə


─────────────────────────  GOOGLE CALENDAR  ─────────────────

Google Calendar artıq real Google Calendar API ilə inteqrasiya olunub.

Dəstəklənir:
   • Tədbirləri oxuma
   • Yeni tədbir yaratma
   • Tədbir silmə

İnteqrasiya əsasən bu fayllarda yerləşir:

   integrations/google/auth.py
   integrations/google/calendar.py

OAuth tokeni:

   config/google_token.json

Bu fayl məxfi məlumat ehtiva edir və repository-yə commit edilməməlidir.


─────────────────────────  QISA YOLLAR  ─────────────────────

   F4    → Mikrofonu susdur / aktiv et
   F5    → Dayandır / davam et
   F6    → Webcam-i aç / bağla
   F11   → Tam ekran
   ESC   → Tam ekrandan çıx


─────────────────────────  WINDOWS QEYDİ  ──────────────────

Webcam və ekran funksiyaları üçün Windows məxfilik icazələri tələb oluna bilər.

Məsələn:
   Settings → Privacy & security → Camera


─────────────────────────  TESTLƏR  ─────────────────────────
